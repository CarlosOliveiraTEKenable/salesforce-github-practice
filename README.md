## Account–Contact Relationship

A Contact can be associated with an Account to show which company they are connected to. For example, **Jordan Lee** is a Contact associated with **Acme Bikes**.

### Practice exercise

1. Create or identify an Account named **Acme Bikes**.
2. Create or identify a Contact named **Jordan Lee**.
3. Associate Jordan Lee with Acme Bikes using the process available in your practice environment.

### Validation checklist

- [ ] The Account is named **Acme Bikes**.
- [ ] The Contact is named **Jordan Lee**.
- [ ] **Verify in a real Salesforce org:** Confirm the Contact is associated with the intended Account.
